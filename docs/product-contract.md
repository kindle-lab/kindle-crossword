# 제품 계약 — 한국일보 크로스워드 Kindle 클라이언트

## 목표

한국일보 PlayGround의 실제 크로스워드를 Kindle Basic 11세대에서 편하게 푸는 것이 목표다. 이 앱은 별도 문제 생성기가 아니고, 한국일보 퍼즐의 표시·입력 클라이언트다.

## 반드시 보존할 것

- 실제 `puzzle.json` 응답의 가로/세로 문제와 정답
- 10×10 좌표와 교차 관계
- 단서(`clue`)와 정의(`definition`)
- 관련 기사 링크(`articleUrl`)
- 동일 퍼즐 여부를 판별할 수 있는 원본 메타데이터 또는 content fingerprint

## 상태 모델

정답 입력은 단어가 아니라 칸에 저장한다.

```text
progress.cells["row,col"] = "한 글자"
```

가로/세로 단어의 현재 입력값은 필요할 때 해당 칸을 순서대로 읽어서 만든다. 따라서 교차점에는 언제나 하나의 문자만 존재한다.

정답 판정도 저장된 boolean을 신뢰하지 않고 현재 칸 상태에서 계산한다.

## 퍼즐 식별

우선순위는 다음과 같다.

1. 원본 응답의 `puzzleId`/동등한 ID
2. 원본 응답의 퍼즐 날짜 + content fingerprint
3. content fingerprint

Kindle의 현재 날짜는 다운로드 시각 기록에는 사용할 수 있지만 퍼즐 identity를 결정하지 않는다.

## 캐시 의미

`puzzle.json`이 최신 퍼즐 하나만 제공하는 현재 구조에서는 앱이 직접 받아 저장한 퍼즐만 과거에 다시 열 수 있다. UI 명칭은 `저장된 퍼즐`로 한다. 서버 아카이브를 발견하고 검증하기 전에는 `과거 퍼즐` 또는 날짜별 전체 아카이브라고 부르지 않는다.

v0.3.x의 raw 퍼즐 캐시는 가능한 범위에서 v0.4 형식으로 이관하되, 단어별 답안 진행상태는 잘못된 모델이므로 이관하지 않는다.

## Kindle UX

- 격자의 칸을 직접 선택한다.
- 교차점에서 같은 칸을 다시 누르면 가로/세로 방향을 전환할 수 있다.
- 한 글자를 입력하면 같은 단어의 다음 칸으로 이동한다.
- `이전 칸`/`다음 칸`으로 이동할 수 있다.
- `단어 확인`은 현재 칸 상태를 기준으로 판정한다.
- 기사 링크가 있으면 `관련 기사에서 힌트 찾기`를 표시한다.
- 네트워크가 없어도 저장된 퍼즐은 열려야 한다.

## 완료 조건

다음 항목이 모두 확인돼야 제품 완료로 본다.

1. 실제 최신 `puzzle.json`과 화면의 문제·정답 좌표가 일치한다.
2. 교차점 문자 하나가 가로/세로 양쪽에 동일하게 반영된다.
3. 교차 문자 변경 시 양쪽 정답 판정이 즉시 재계산된다.
4. 관련 기사 링크가 보존되고 열 수 있다.
5. 동일 퍼즐 재다운로드가 중복 날짜 퍼즐로 저장되지 않는다.
6. 네트워크 없이 저장된 퍼즐과 진행상태가 복원된다.
7. Kindle Basic 11세대 + Vera + 대상 펌웨어에서 터치와 한글 입력을 실측한다.
